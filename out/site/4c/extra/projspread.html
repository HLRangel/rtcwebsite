VOLUNTEER PROJECT MASTER BOARD

Task Description Notes and Resources






The Big List of Communism – Addition of new websites Adding more websites to TBLOC is desirable; not only websites of groups or individuals in the tendency of the Communist Left, but of those in the Left Opposition in general, such as “Trotskyist” groups. Please ask for orientation on Discord or other channels.

Git repository ZIP: https://tbloc.comrades.sbs/tbloc.git.zip

The Big List of Communism – Updated German translation TBLOC has been missing a German translation ever since its last maintainer became inactive. It would be good to get someone to work on it again. Please ask for orientation on Discord or other channels. No skills relevant to the web project needed, assistance will be provided on those aspects.

Git repository ZIP: https://tbloc.comrades.sbs/tbloc.git.zip

Esperanza First supposed to be a semi-regular publication, currently taking the form of an anuary of RTC works, it has been in a harsh situation ever since it missed its intended release window of January 2025. Since then, some of its texts have been released separately on the website. Please ask for orientation on Discord or other channels in order to be given access to the ODF document.

Ploogly SSG A Static Site Generator written in Rust, developed for use with the Faust website. It is currently used for the RTC website, though it contains several bus and has limited usefulness. Please ask for orientation on Discord or other channels in order to be given access to the Git repository.

RTC Audiophonic Services – Website The website for the RTC Audiophonic Services audio stream. Very early development. Please ask for orientation on Discord or other channels to see how you can help.

RTC Audiophonic Services – Music Library The music library for the RTC Audiophonic Services audio stream. It should contain only music in the Public Domain or under a Creative Commons license. CC-NC (Non-Commercial) is a permissible compromise. Suggest music on the Discord or other channels. Ask for the current state of the music library.

ICED – Pre-Registration Pre-registration page for a prediction platform for US-ICE service incidents affecting agents. Please ask for orientation on Discord or other channels.

The COPYRIGHT-HATERS Handbook. An anti-Copyright treatise which clarifies what it actually is and encourages people to release their work into the Public Domain (or settle for a Copyleft compromise) First draft being actively worked on, in an early stage. Ask for an early manuscript.

HedgeDoc Instance A HedgeDoc instance with some very small modifications in regards to functionality and stylesheets. Please ask for orientation on Discord or other channels in order to be given access to the Git repository.

Mailing List A mailing list for RTC affairs. While we have settled on a provider, financial considerations mean we cannot go forward with it yet.

Library of the Communist Left Podcast Player An audio player for Library of the Communist Left podcast episodes, to be developed in exchange for the release of all LCL episodes under a Creative Commons license. Not being worked on.

General Strike Coordination Application General Strike coordination application for the United States. Likely irrelevant now, given the current political scenario of the country. Not being worked on. Complex project.
